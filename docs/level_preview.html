Level rendering preview

Mock 5m chart using the same alpha stack, weights, dim values and label de-collision as the Pine draw pass — a check on the look before pasting.

Majors (walls, flip, control node) carry the heaviest halo and sit at full opacity. Secondary walls, midpoints, expected-move and session levels are progressively dimmed so they read as context rather than competing with the levels price is actually working. Distance fade pushes far levels back further still.
